# ADR-0002: 較正の形 — ステージ・層・プロジェクタの配置

## 状態

採用 (2026-11-09)

## 文脈

ADR-0001 決定 6 は、較正を「表示装置 → 領域 (=プロジェクタ) → 4 隅」で持ち、1 つの領域に映像を 1 本丸ごと写した。これでは次のことができない ([#20](https://github.com/mokume-metal/mokumesh/issues/20))。

- 映像の一部を切り取って映す
- 1 台のプロジェクタで、別々の面に別々の切り抜きを映す
- 複数のプロジェクタにまたがって 1 つの面を映す (領域ごとに絵が閉じている)

GUI を MadMapper / Unity に倣ったペイン (階層・入力・ステージ・プロジェクタ配置・出力) に分けるにあたり、MadMapper (5 系) の機能の割り当てと並べて形を決めた。

| MadMapper | mokumesh | 判断 |
| --- | --- | --- |
| Surfaces の一覧 (Quad・Mesh・Mask など) | 層 (`layers`) の面 | 形は Quad だけで始める。Mesh は ADR-0001 決定 5 の後続 |
| Input View: 面ごとに入力の**四角形 (4 隅)** を選ぶ | 面の `input` (4 隅) | 矩形の crop より一般で、描画の行列は 1 本のまま |
| Output View: 全プロジェクタを合わせた画布で面を歪める | ステージ | 同じ |
| Masks: 一覧の項目として出力の空間に置き、下を覆う | 層のマスク | 面の属性にせず、層にする。面と無関係に「扉には映さない」を表せる |
| Output Setup: 仮想のプロジェクタを画布に並べる。画布はその外形 | 領域の `placement`。ステージの外形はその外接矩形 | 同じ |
| Projector warping | 領域の `keystone` | 同じ |
| 不透明度・合成モード・色・FX・Scenes・Cues | 持たない | 作品の仕事 (ADR-0001 決定 1) |

## 決定

### 1. 面は共通のステージに置き、プロジェクタはステージを覗く窓にする

- **ステージ**: 面を置く共通の平面。座標は**画素**。外形は保存せず、全領域の `placement` の外接矩形として求める。配置を変えても面の位置が動かないよう、正規化しない
- **層** (`layers`): ステージに置く面とマスク。並びが描く順で、先のものが下
  - **面**: 映像の名前・切り取り (`input`: 映像の中で 0〜1 の 4 隅)・置く先 (`corners`: ステージの画素の 4 隅)
  - **マスク**: ステージの画素の多角形。自分より下に描いたものを、外側 (反転なら内側) で黒くする
- **領域**: ADR-0001 決定 6 の「表示装置 → 領域」の 2 段はそのまま。領域は、ステージの `placement` の範囲を、`keystone` (範囲の 4 隅を写す先・領域の中で 0〜1) で台形補正して映す

ADR-0001 決定 5 の「2D の面は平らなモデル・mokumesh は視点から描く」とは、ステージ = 平らなモデル、領域の placement と keystone = 視点、として重なる。

### 2. 描画は面ごとに行列 1 組

領域の中の点 q に映るものは、q → 受け持つ範囲の中の位置 (keystone の逆) → ステージの点 (placement) → 面の中の位置 (corners の逆) → 映像の中の位置 (input) で決まる。CPU で 3 本の行列 (範囲・面・切り取り) を作り、断片で範囲の外と面の外を捨て、残りを乗算済みの over で層の順に重ねる (`MappingConfig.mapping`)。

### 3. 版 1 は読み替える

版 1 の領域は、映像全体を 4 隅へ写していた。これは「受け持つ範囲を覆う面 1 枚と、4 隅を keystone にした領域」と同じ絵になる。領域ごとに 1920×1080 の範囲を横に並べて読み替え、保存は常に版 2 で書く。

**退けた案**:

- **領域に切り取りとマスクを足すだけ** (2 段のまま)。小さいが、1 台に複数の切り抜きを置けず、複数台にまたがる面も表せない
- **ステージを 0〜1 に正規化する**。プロジェクタを足す・動かすたびに外形が変わり、置いた面がずれる
- **ステージの大きさを保存する**。プロジェクタ配置と食い違いうる値を 2 か所に持つことになる
- **マスクを面の属性にする**。面に追従はするが、面に関係なく光を止めたい場所 (扉・観客) を表せず、複数の面を 1 枚で覆えない。面に追従させたいときは、面の真上にマスクを置けば済む
- **切り取りを矩形にする**。斜めに撮った素材を正しく取り出せない。4 隅にしても描画の費用は変わらない

**代償**:

- 設定は 3 種の座標 (映像の 0〜1・ステージの画素・領域の 0〜1) を持つ。Schema の説明で単位を明記する
- 版 1 から読み替えた設定の placement は、表示装置の実際の解像度ではなく 1920×1080 になる。映る絵は同じだが、プロジェクタ配置のペインで見た大きさは実物と違いうる
- マスクの形は版 2 に入っているが、描くのは [#25](https://github.com/mokume-metal/mokumesh/issues/25) からで、それまでは読み書きだけする

## 影響

- ADR-0001 決定 6 の「較正・マスク・ブレンドは領域ごと」は、この ADR で「台形補正とブレンドは領域ごと、面とマスクはステージの層」に改める
- GUI のペインは、層の木 (階層)・`input` (入力)・`corners` とマスク (ステージ)・`placement` と `keystone` (プロジェクタ配置)・領域ごとの結果 (出力) を編集・表示する
